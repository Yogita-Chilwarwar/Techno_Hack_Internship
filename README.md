# Raisoni College Landing Page

A modern, responsive landing page for Raisoni College built with HTML, CSS, and JavaScript.

## Features

### 🎨 Modern Design
- Clean and professional layout
- Responsive design that works on all devices
- Beautiful gradient backgrounds and smooth animations
- Modern typography using Inter font

### 📱 Responsive Layout
- Mobile-first approach
- Hamburger menu for mobile devices
- Flexible grid layouts that adapt to screen size
- Optimized for desktop, tablet, and mobile

### ⚡ Interactive Elements
- Smooth scrolling navigation
- Hover effects and animations
- Form validation and submission handling
- Loading animations and progress indicators
- Counter animations for statistics
- Typing effect on hero title

### 🎯 Key Sections
- **Hero Section**: Eye-catching introduction with call-to-action buttons
- **About Section**: Mission, vision, and key statistics
- **Programs Section**: Academic programs with icons and descriptions
- **Admissions Section**: Benefits and information request form
- **Campus Life**: Student activities and facilities
- **Contact Section**: Contact information and contact form
- **Footer**: Social links and additional information

## File Structure

```
├── index.html          # Main HTML file
├── styles.css          # CSS styles and responsive design
├── script.js           # JavaScript functionality
└── README.md           # Project documentation
```

## Getting Started

1. **Clone or download** the project files
2. **Open** `index.html` in your web browser
3. **Customize** the content, colors, and styling as needed

## Customization

### Colors
The main color scheme uses:
- Primary Blue: `#2563eb`
- Secondary Blue: `#1d4ed8`
- Gradient: `#667eea` to `#764ba2`

### Content
- Update the college name, contact information, and statistics
- Replace placeholder text with actual content
- Add real images instead of icon placeholders
- Modify program offerings and descriptions

### Styling
- Colors can be changed in the CSS variables
- Fonts can be updated by changing the Google Fonts import
- Layout can be adjusted by modifying the CSS grid properties
